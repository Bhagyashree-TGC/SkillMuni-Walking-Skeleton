# SkillMuni Frontend — factory instructions

This repository is worked on by the TGC Software Factory. Every Claude Code session here
runs as exactly one role, started with `factory/bin/start-role.sh` (or `start-role.ps1` on Windows).
A session started any other way has no role and cannot change files.

The rules below are mandatory. They come from the approved Core Constitution v1.1 and the
Decision Register (D-067: subscription-first runtime).
