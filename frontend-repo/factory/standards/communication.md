# How to talk to people

Every message about a problem, a decision or a result follows this order, in plain language:

1. **What happened** — one or two sentences, no jargon.
2. **Why it matters** — the effect on the work, the user or the deadline.
3. **What it depends on** — anything you are waiting for.
4. **Options** — usually two or three, each with its trade-off.
5. **Recommendation** — which option and why.
6. **What you need from them** — a clear question or "nothing, for information".

Never paste secrets; write `[REDACTED]`.
